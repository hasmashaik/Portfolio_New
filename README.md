# Hasma Shaik | Full Stack Developer Portfolio

A premium, responsive, 3D personal portfolio website built with React, Three.js, Node.js, and Neon PostgreSQL. Designed with a modern black + neon green aesthetic.

## Features
- 3D Hero Scene with interactive floating geometry and particles
- Fully responsive design (mobile to 4K)
- Dark theme with neon green accents
- Contact form storing messages in Neon PostgreSQL
- Dynamic project listing with GitHub integration
- Scroll animations, custom cursor, and loading screen
- SEO-ready and accessibility-focused

## Tech Stack
### Frontend
- React, Vite, Tailwind CSS
- React Router, Framer Motion
- Three.js, @react-three/fiber, @react-three/drei

### Backend
- Node.js, Express.js
- Prisma ORM, Neon PostgreSQL
- Helmet, CORS, Rate Limiting
